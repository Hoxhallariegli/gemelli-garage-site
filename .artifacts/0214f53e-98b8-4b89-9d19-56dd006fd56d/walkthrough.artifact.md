# Relocated Admin Login Button

The "Admin Login" button has been moved to provide a cleaner header experience.

## Changes Made

### UI Refactor
- Removed the green "Admin Login" button from the main navigation header.
- Added the "Admin Login" button to the bottom of the side menu overlay (extra-content).
- The button now spans the full width of the side menu for better accessibility on mobile.

## Verification Results
- Header is now less cluttered.
- Admin Login is accessible via the side menu (burger icon/extra button).
